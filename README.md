# Python Projects Lab

Welcome to my Python learning and practice repository! This space is dedicated to building clean, structured, and production-grade utility projects as I level up my software development skills.

## Project Index

Here is a list of mini-projects included in this repository:

1. **[01_CLI_Calculator](./01_CLI_Calculator)**: A professional, loop-driven CLI calculator implementing advanced exception handling (`try-except-finally`), custom error raising, and input sanitization.

2. **[02_Library-management-system](./02_Library-management-system)**: An OOP-based Library Management System — built with `Book` and `Library` classes, JSON-based persistence, and full CRUD operations (add, issue, return, search) with layered business-logic validation.

3. **[03_DSA_practice](./03_DSA_practice)**: A growing collection of data structures and algorithms exercises — covering two-pointer techniques, sliding window patterns, hashing, and classic LeetCode-style problems (Two Sum, Move Zeroes, Longest Substring Without Repeating Characters, Group Anagrams).

4. **[04_SQLite_Student_Management](./04_SQLite_Student_Management)**: A Student Records CRUD system built with Python's `sqlite3` module — featuring parameterized queries (SQL-injection safe), input validation, and proper database connection handling.

5. **[05_Numpy_Pandas](./05_Numpy_Pandas)**: Practice exercises covering NumPy (vectorized operations, broadcasting, boolean indexing) and Pandas (DataFrames, missing value handling, duplicates, groupby) — foundational skills for data cleaning and analysis.

6. **[06_Titanic_EDA](./06_Titanic_EDA)**: An end-to-end Exploratory Data Analysis project on the Titanic dataset — data cleaning, survival-rate analysis by gender and class, and visualizations built with Matplotlib and Seaborn.
