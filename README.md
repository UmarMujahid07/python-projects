# Python Projects Lab

Welcome to my Python learning and practice repository! This space is dedicated to building clean, structured, and production-grade utility projects as I level up my software development skills.

## Project Index

Here is a list of mini-projects included in this repository:

1. [01_CLI_Calculator](https://github.com/UmarMujahid07/python-projects/blob/main/01_CLI_Calculator): A professional, loop-driven CLI calculator implementing advanced exception handling (`try-except-finally`), custom error raising, and input sanitization.

2. [02_Library-management-system](https://github.com/UmarMujahid07/python-projects/blob/main/02_Library-management-system): An OOP-based Library Management System — built with `Book` and `Library` classes, JSON-based persistence, and full CRUD operations (add, issue, return, search) with layered business-logic validation.

3. [03_DSA_practice](https://github.com/UmarMujahid07/python-projects/blob/main/03_DSA_practice): A growing collection of data structures and algorithms exercises — covering two-pointer techniques, sliding window patterns, hashing, and classic LeetCode-style problems (Two Sum, Move Zeroes, Longest Substring Without Repeating Characters, Group Anagrams).

4. [04_SQLite_Student_Management](https://github.com/UmarMujahid07/python-projects/blob/main/04_SQLite_Student_Management): A Student Records CRUD system built with Python's `sqlite3` module — featuring parameterized queries (SQL-injection safe), input validation, and proper database connection handling.

5. [05_Numpy_Pandas](https://github.com/UmarMujahid07/python-projects/blob/main/05_Numpy_Pandas): Practice exercises covering NumPy (vectorized operations, broadcasting, boolean indexing) and Pandas (DataFrames, missing value handling, duplicates, groupby) — foundational skills for data cleaning and analysis.

6. [06_Titanic_EDA](https://github.com/UmarMujahid07/python-projects/blob/main/06_Titanic_EDA): An end-to-end Exploratory Data Analysis project on the Titanic dataset — data cleaning, survival-rate analysis by gender and class, and visualizations built with Matplotlib and Seaborn.

7. [07_Machine_Learning](https://github.com/UmarMujahid07/python-projects/blob/main/07_Machine_Learning): Fundamentals of core machine learning concepts — supervised vs. unsupervised paradigms, train-test splits, feature scaling, model validation techniques, and evaluation metrics.

8. [08_Vehicle_Resale_Price_Estimator](https://github.com/UmarMujahid07/python-projects/blob/main/08_Vehicle_Resale_Price_Estimator): An end-to-end regression machine learning pipeline predicting used car prices — featuring feature engineering (`Car_age`), One-Hot Encoding, model comparison (Linear Regression vs. Random Forest Regressor), 5-fold cross-validation, and feature importance analysis.

9. [09_FastAPI_basics](https://github.com/UmarMujahid07/python-projects/blob/main/09_FastAPI_basics): An introduction to building web APIs with FastAPI — covering routing, path and query parameters, type-hint-based validation, and FastAPI's automatic interactive documentation (`/docs`).
